이름이 실장이어도 “밑에 둔다”면 보좌기관입니다.

01 · LINE

“X에 A를 둔다”

A는 X의 보조기관입니다. 실·국·본부·관·과를 실선 계선으로 잇습니다. 다만 “장관 소속으로 … 지원하기 위하여”가 붙으면 본부라는 이름이어도 부속기관으로 분리합니다.

02 · STAFF

“Y 밑에 D를 둔다”

D는 Y의 보좌기관입니다. 기획조정실장·대변인처럼 계선 이름을 가진 직위도 문형이 우선합니다.

03 · OPERATING

“정책관 내 다른 과”

관도 과·담당관·팀을 거느립니다. 시행규칙 업무분장상 소관은 법정 설치계선과 분리해 운영형에서만 점선으로 얹습니다.
