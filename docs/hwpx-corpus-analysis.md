# HWPX 취합본에서 추출한 기구도 유형

`2026년 정기직제 검토서.hwpx`를 원본 수정 없이 압축 해제하여 분석했다. 문서는 79개 섹션과 `BinData` 그림 668개를 포함하고, 일부 섹션은 HWPX의 선·사각형·연결선·그룹 도형으로 조직도를 직접 그린다. 다른 섹션은 PPT/이미지로 붙인 조직도를 사용한다.

## 반복되는 작도 유형

| 유형 | 관찰된 특징 | 생성기 대응 |
| --- | --- | --- |
| 세로 척추형 | 기관장·차관을 세로로 놓고 실·국·관을 아래 버스에 연결 | `--paper a4-portrait --layout vertical` |
| 반쪽 A4 세로형 | 좁은 폭에 관·국·과를 세로로 쌓고 과명은 세로쓰기 | `--paper a4-half --layout vertical` |
| 가로 버스형 | 기관장 아래 여러 실·국을 한 줄에 배열 | `--paper a4-landscape --layout horizontal` |
| 관·국–과 스택형 | 관 또는 국을 부모 상자로 두고 과를 좁은 상자로 연속 배치 | `vertical-stack`의 세로 leaf와 시행규칙의 계층 관계 |
| 본부·소속기관 분리형 | 본부 계선과 소속기관/책임운영기관을 다른 띠나 별도 트리로 표시 | 법정 그래프의 `affiliated` 계통과 별도 페이지 |
| 현행·요구 비교형 | 같은 조직을 좌우 두 묶음으로 그리고 신설·명칭변경·이체를 색/점선으로 표시 | `@변경: 조직명 = 신설|폐지|명칭변경|이체|상계신설` |
| 기능·업무 흐름형 | 조직 상자 사이에 화살표와 설명을 넣어 기능 이관을 표시 | 조직관계는 그래프에 보존하고, 업무 흐름은 주석·운영형 보기로 분리 |
| 매트릭스·기관 목록형 | 지방청·서무서·소속기관을 여러 열의 표처럼 나열 | 과도한 leaf를 자동 분할하고 소속기관 페이지로 이동 |

같은 문언을 여러 시각 문법으로 비교해야 하는 경우에는 `--layouts vertical,horizontal,two-column,matrix`를 지정한다. 네 프리셋은 동일한 법정 그래프를 공유하므로, 유형별 차이는 작도 방식에만 있고 보조기관·보좌기관·부속기관의 판정은 변하지 않는다.

## 대표적인 HWPX 근거

그림 리소스의 번호는 HWPX 내부 `binaryItemIDRef`와 일치한다. 번호는 법적 근거가 아니라 시각 유형을 재현하기 위한 분석용 표본이다.

- `image26`, `image28`: 상단 기관장–하단 부서의 가로·세로 트리
- `image49`, `image107`, `image108`: 좁은 폭의 세로형 조직도
- `image196`–`image199`, `image205`–`image211`, `image223`–`image227`: 기관장 상자와 과 목록을 반복하는 소속기관/본부형
- `image24`, `image25`, `image254`, `image257`, `image258`: 현행·요구 또는 변경 전·후 비교형
- `image331`–`image345`: 과·관 단위의 고전적인 수직 상자 트리
- `image262`–`image266`, `image282`, `image283`: 색상과 점선으로 이관·신설을 표시한 비교형

도형 중심으로는 행정대상 기관의 비교표에서 다음 패턴이 반복되었다.

- `section18`: 정책관 아래 과를 두 묶음으로 나눈 뒤 증원·분리 신설을 보라색 연결선으로 표시
- `section43`: 해양경찰청·지방청·서의 계층을 선·사각형·연결선과 텍스트 도형으로 직접 작성
- `section51`: 위원장–상임위원–사무처–관–과의 세로 계선과 신설 표식
- `section76`: 항공교통본부·국·과·센터를 여러 열로 나누고 직급조정·상계신설을 주석으로 표시

## A4 출력 규칙

페이지 크기와 레이아웃은 서로 독립적으로 선택한다.

```bash
# A4 세로 한 장
node src/cli.mjs build --input 직제.txt --paper a4-portrait --layout vertical \\
  --out outputs/기관-a4.pptx --svg outputs/기관-a4.svg

# A4를 세로로 반으로 나눈 한 쪽. 두 결과를 2-up으로 배치할 수 있다.
node src/cli.mjs build --input 직제.txt --paper a4-half --layout vertical \\
  --focus 산업정책실 \\
  --out outputs/기관-반쪽.pptx --svg outputs/기관-반쪽.svg

# 가로형 검토서
node src/cli.mjs build --input 직제.txt --paper a4-landscape --layout horizontal \\
  --out outputs/기관-가로.pptx
```

`a4-half`는 A4 세로 폭의 절반(`297.64 × 841.89`)으로 하나의 조직도만 출력한다. PPTX와 SVG 모두 같은 종횡비를 사용하므로 편집 후 인쇄용 조판에 넣을 수 있다. 본부와 부속기관은 파서의 설치 문형을 따르며, `장관 소속으로 …를 둔다`는 소속기관, `부에 …를 둔다`는 본부 계선으로 분리한다.

`--focus 조직명`을 함께 주면 해당 실·국·관과 그 하위 과만 출력하므로, 예시 사진처럼 한 면에 들어갈 한쪽 조직도를 직접 만들 수 있다.

## 한계와 다음 확장

- HWPX에 붙은 사진·스크린샷의 문자를 자동으로 법적 조직관계로 확정하지 않는다. 이미지에서 읽은 이름은 직제·시행규칙 원문으로 교차 확인해야 한다.
- 실제 검토서의 증원 수, 상계 인원, 주석은 `@변경`과 메타데이터로 명시하면 재현할 수 있다.
- 별표에 위임된 지방기관 목록은 별표 파서가 연결될 때만 완전한 기관 트리로 만들 수 있다.
