# 참조 PPT 분석과 법적 조직 모델

## 분석 대상

| 기관 | 기준일 | 슬라이드 | 첫 슬라이드 도형 수 | 특징 |
|---|---:|---:|---:|---|

| 문화체육관광부 | 2025-07-01 | 7 | 160 | 제1·제2차관 계통과 다수 소속기관을 별도 분기 |
| 공정거래위원회 | 2025-10-13 | 2 | 186 | 합의제 기관의 위원장·부위원장·상임위원·사무처 구조 |
| 2026년 중앙행정기관 취합본 | 2026-03-31 | 61개 PPTX / 185슬라이드 + 범례 1슬라이드 | 기관별 상단 집계표, 직렬·임용 약호, 소속기관·한시·책임운영 표식 교차 검증 |

세 파일 모두 1122.67 × 720px 비율의 빈 화면 슬라이드 위에 네이티브 도형과 선을 직접 배치한다. 2026년 취합본도 같은 화면비와 인쇄용 여백을 반복한다. 공통적으로 흰 배경, 얇은 회색 선, 파란색 기관장 상자, 초록색 소속기관 상자를 사용한다. 원본 자료 사이에는 굴림·맑은 고딕·윤명조 등 글꼴 차이가 있으므로 글꼴명은 구조 규칙이 아니라 디자인 테마로 취급한다.

## 공통 시각 문법

| 의미 | PPT 표현 | 프로그램 표현 |
|---|---|---|
| 기관장·부기관장 | 파란색 둥근 가로 상자 | `head`, `deputy` |
| 실·국·본부·관 | 흰색 또는 옅은 회색 가로 상자 | `assistant` 또는 `advisor` |
| 과·팀 | 좁고 긴 세로 상자 | 말단 노드 자동 세로화 |
| 보조·지휘 | 실선 | `assistant`/`structural` edge |
| 보좌 | 점선 또는 측면 연결 | `advisor` edge |
| 소속기관 | 초록색 상자 | `affiliated` edge/node |
| 한시·자율·총액·평가 | 별도 색·작은 원형 표식·기한 주석 | 메타데이터와 문자 표식 |
| 직렬·임용 범주 | `연`·`지`·`전`·`임`·`별`·`특` 표식 | `metadata.staffCategories`, `employmentType`, `specificRank` |
| 집계표 | 우측 상단의 기구표·정원표 2단 | 향후 `summaryTables` 메타데이터/인쇄 레이아웃 |
| 슬라이드 계속 | 상단 수평선과 끊긴 연결선 | 개요 페이지 뒤 분할 페이지 |

행정안전부·문체부 자료는 과 단위를 세로로 세워 한 장의 정보 밀도를 높인다. 공정위 자료는 위원·사무처와 조사·심판 계통이 나란히 놓이는 합의제 기관형이다. 따라서 하나의 고정 템플릿보다 조직 그래프의 크기와 기관 유형에 따라 페이지를 계획해야 한다.

### 2026년 취합본에서 추가로 확인한 표식

2026년 3월 31일 취합본의 별도 범례와 기관별 도표를 대조하면 다음 정보가 반복된다.

- 제목은 왼쪽 기관명, 오른쪽 `< YYYY.M.D. 기준 >`으로 구성된다.
- 우측 상단에는 `기구`와 `정원` 두 집계표가 놓인다. 기구표는 보조기관·보좌기관·소속기관을 고공단(가·나), 3·4급, 4급, 4·5급 및 소속기관 1·2·3차로 나눈다. 정원표는 정무직, 고공단, 직급별 정원, 연구직·지도직, 전문직, 전문경력관, 임기제(고공), 특정직, 별정직(고공)을 분리한다.
- 상자 옆의 `가/나`는 고위공무원단 직무등급이며, `연`·`지`·`전`·`임`·`별`·`특`은 연구직·지도직·전문직/전문경력관·임기제·별정직·특정직 표식이다. 같은 글자라도 범례에서는 채움·테두리로 세부 범주를 구별하므로 모델은 범주를 합치지 않고 보존한다.
- `책임`, `총액`, `자율`, `한시`는 조직 종류가 아니라 운영·정원·존속 상태를 덧붙이는 표식이다. 기한은 `YYYY.M.D.까지` 또는 `YYYY.M.D.부터`로 별도 기록한다.

현재 렌더러는 이 표식을 노드명에 안전하게 표시하고, 집계표는 `summaryTables`를 위한 후속 인쇄 레이아웃 대상으로 남겨 둔다. 따라서 법적 관계와 직렬·임용 메타데이터를 먼저 확정한 뒤 글꼴·색상·상단표 디자인을 독립적으로 교체할 수 있다.

## 법적 개념

「행정기관의 조직과 정원에 관한 통칙」의 핵심 문언:

- 제2조제6호: 보조기관은 행정기관의 의사·판단의 결정이나 표시를 보조하는 기관
- 제2조제7호: 보좌기관은 기관장이나 보조기관을 보좌하는 기관
- 제2조제8호: 하부조직은 보조기관과 보좌기관
- 제12조: 정책관·기획관·담당관 등 보좌기관
- 제14조: 실·국·과 등 보조기관, 실 밑에는 국 또는 과, 국 밑에는 과
- 제17조의3: 한시적 보조기관·보좌기관과 존속기간
- 제19조: 부속기관과 그 하부조직
- 제29조: 총액인건비제 특례
- 제31조: 신설 조직·정원 평가

공식 원문: [행정기관의 조직과 정원에 관한 통칙](https://www.law.go.kr/법령/행정기관의조직과정원에관한통칙)

## 직제와 시행규칙을 함께 읽는 이유

대통령령인 직제는 보통 다음을 확정한다.

- 기관장·차관·부위원장
- 실·국·본부와 주요 보좌기관
- 소속기관
- 한시조직·평가대상 조직의 근거

총리령·부령인 시행규칙은 다음을 구체화한다.

- 실·국 밑의 과·팀
- 정책관·기획관·담당관의 명칭
- 소속기관의 하부조직
- 조직별 직급

따라서 직제만 파싱하면 과·팀이 빠지고, 시행규칙만 파싱하면 기관장부터 실·국까지의 상위 관계가 불완전해진다.

## 파서의 중간 모델

```text
법령 평문
  → 조문 단위 분리
  → 기관·조직명 정규화
  → 관계 추출
  → 직제/시행규칙 노드 병합
  → 조직 그래프
  → 페이지 계획
  → PPTX/SVG
```

노드의 주요 필드:

- `name`: 법령상 조직명
- `kind`: `head`, `deputy`, `assistant`, `advisor`, `affiliated`, `temporary`
- `rank`: 시각적 계층
- `metadata`: 존속기한, 총액인건비, 자율, 평가
- `sources`: 관계를 뒷받침한 입력 문서

관계의 주요 필드:

- `parent`, `child`
- `type`: `structural`, `assistant`, `advisor`, `affiliated`, `temporary`
- `sources`

동일한 과명이 여러 지방사무소에 반복되거나 하나의 보좌기관이 상위 기관장과 보조기관을 함께 보좌하는 경우가 있어 그래프는 다중 부모를 허용한다.

## 레이아웃 선택

`auto`는 다음 순서로 동작한다.

1. 작은 조직은 한 장에 전체 계층을 배치
2. 큰 조직은 기관장·부기관장과 상위 기구만 보여주는 개요 페이지 생성
3. 실·국·관 하위조직을 노드 수 한도 안에서 여러 분기로 묶음
4. 큰 분기는 재귀적으로 분할
5. 소속기관은 초록색 계통으로 별도 묶음
6. 말단 과·팀 수가 많으면 세로 상자로 전환

이 방식은 원본 PPT의 수평 분할 관행을 유지하면서도 기관별 슬라이드 수를 고정하지 않는다.
